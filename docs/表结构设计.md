# 表结构设计

> 定位：个人 / 小组织自用。模型由用户自行配置（类似 CCswitch），平台不提供模型选项；用户自带 API KEY，不关心计费与封禁。
> 约定：
> - 时间统一 UTC，字段统一 `created_at` / `updated_at` / `deleted_at`。
> - 字符集 `utf8mb4`（支持 emoji）。
> - 可同步的表用 `updated_at` 标识变更、`deleted_at`（NULL 表示未删除）做软删墓碑，供客户端与云端增量同步。
> - 认证用 JWT 无状态令牌，不单独建 token 表。

1. 用户表 `user`

只保留登录所需的最小信息，不做封号、角色、资料体系。

|字段|类型|含义|取值|
|-|-|-|-|
|id|char(36) primary-key|用户身份ID|UUID|
|username|varchar(64) unique|登录账号，全局唯一|字母、数字、下划线|
|nickname|varchar(64)|显示昵称|any|
|password|varchar(255)|密码哈希|bcrypt / argon2 哈希值|
|created_at|datetime|账号创建时间|合法时间|
|updated_at|datetime|账号更新时间|合法时间|

2. 用户模型配置表 `model_config`

用户自己维护的模型连接配置，类似 CCswitch：一套配置包含名称、接口地址、模型名和 API KEY。平台不预置模型选项，一个用户可以有多套，会话和消息引用其中一套。

|字段|类型|含义|取值|
|-|-|-|-|
|id|char(36) primary-key|模型配置ID|UUID|
|user_id|char(36)|所属用户ID|UUID|
|display_name|varchar(128)|配置名称|如 “DeepSeek 官方”|
|provider|varchar(32)|提供方标识|deepseek、openai、custom 等，仅用于界面预填|
|model_name|varchar(128)|请求接口时使用的模型名|如 deepseek-chat|
|base_url|varchar(512)|接口地址|URL，如 https://api.deepseek.com/v1|
|context_window|int|上下文窗口大小，单位为token|默认 128000|
|max_output_tokens|int|单次最大输出token数|默认 4096|
|api_key_ciphertext|varchar(512)|加密后的 API KEY|密文|
|api_key_nonce|varchar(64)|加密 nonce|any|
|api_key_salt|varchar(64)|密钥派生盐|any|
|is_default|tinyint|是否用户默认模型|0否，1是；同一用户最多一个默认|
|is_active|tinyint|是否启用|0停用，1启用|
|created_at|datetime|创建时间|合法时间|
|updated_at|datetime|更新时间|合法时间|
|deleted_at|datetime|删除时间，NULL 表示未删除|合法时间|

> API KEY 使用 AES-256-GCM 加密，nonce / salt 与密文分开存，不落明文；查询接口只返回掩码。
> 用户删除配置走软删，已引用它的会话和消息将 `model_config_id` 置空，回退到用户默认模型。

3. 系统提示词 `system_prompts`

|字段|类型|含义|取值|
|-|-|-|-|
|id|int primary-key|提示词ID|唯一ID，0 为默认提示词|
|user_id|char(36)|所属用户ID，NULL 表示内置提示词|UUID 或 NULL|
|name|varchar(256)|提示词标识|简单介绍|
|prompt|text|提示词内容|prompt|
|created_at|datetime|创建时间|合法时间|
|updated_at|datetime|更新时间|合法时间|
|deleted_at|datetime|删除时间，NULL 表示未删除|合法时间|

> 初始化脚本必须先插入 `id = 0` 的默认提示词，再让 `session.system_prompt` 以 0 为默认值，否则外键约束会失败。

4. 会话 `session`

|字段|类型|含义|取值|
|-|-|-|-|
|id|char(36) primary-key|会话ID|UUID|
|title|varchar(128)|会话识别标题|any|
|user_id|char(36)|所属用户ID|UUID|
|model_config_id|char(36)|该会话使用的模型配置，NULL 表示跟随用户默认模型|UUID 或 NULL|
|system_prompt|int|系统提示词ID，默认 0|合法ID，0 为默认提示词|
|input_token_used|bigint|累计输入token|any|
|output_token_used|bigint|累计输出token|any|
|is_pinned|tinyint|是否置顶|0否，1是|
|sort_order|int|列表排序权重，越大越靠前|any|
|last_conversation_at|datetime|上次对话时间|合法时间|
|created_at|datetime|创建时间|合法时间|
|updated_at|datetime|更新时间（改标题、换模型等）|合法时间|
|deleted_at|datetime|删除时间，NULL 表示未删除|合法时间|

> 上下文上限由 `model_config.context_window` 提供，会话不重复存 `max_context` / `used_context` / `msg_count`，避免冗余漂移；token 累计值由消息表汇总维护。

5. 对话表 `chat_message`

|字段|类型|含义|取值|
|-|-|-|-|
|id|char(36) primary-key|消息ID|UUID|
|session_id|char(36)|所属会话ID|UUID|
|parent_id|char(36)|父消息ID，用于重新生成/分支|UUID 或 NULL|
|seq|bigint|会话内消息序号，保证顺序稳定|单调递增|
|model_config_id|char(36)|生成该消息的模型配置|UUID 或 NULL|
|model_name|varchar(128)|生成时的模型名快照|any|
|role|varchar(16)|发送对象|system、user、assistant、tool|
|content|mediumtext|消息内容|文本|
|reasoning_content|mediumtext|模型思考内容|文本或 NULL|
|input_token|int|本条输入token|any|
|output_token|int|本条输出token|any|
|msg_status|tinyint|会话状态|0正常，1生成中，2失败，3撤回|
|error_message|varchar(512)|失败原因|any|
|created_at|datetime|生成时间|合法时间|
|updated_at|datetime|更新时间（编辑、状态流转）|合法时间|
|deleted_at|datetime|删除时间，NULL 表示未删除|合法时间|

> 排序以 `seq` 为准，不依赖时间；`model_name` 做快照，模型配置被删后历史消息仍可追溯。

6. 索引与外键

|对象|类型|说明|
|-|-|-|
|user.username|unique|登录账号唯一|
|model_config(user_id, deleted_at)|index|用户模型列表|
|system_prompts(user_id)|index|用户提示词|
|session(user_id, deleted_at, last_conversation_at)|index|用户会话列表|
|session(user_id, is_pinned, sort_order)|index|置顶排序|
|chat_message(session_id, seq)|index|按会话顺序拉取消息|
|chat_message(parent_id)|index|重新生成/分支|
|model_config.user_id|foreign key → user.id|CASCADE|
|system_prompts.user_id|foreign key → user.id|SET NULL|
|session.user_id|foreign key → user.id|CASCADE|
|session.model_config_id|foreign key → model_config.id|SET NULL|
|session.system_prompt|foreign key → system_prompts.id|SET NULL|
|chat_message.session_id|foreign key → session.id|CASCADE|
|chat_message.model_config_id|foreign key → model_config.id|SET NULL|
|chat_message.parent_id|foreign key → chat_message.id|SET NULL|
