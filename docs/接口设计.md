# 接口设计

> 约定：
> - 下列路径省略前导 `/`，完整地址为 `/api/v1/...`。
> - 除注册、登录外，其余接口都需要请求头 `Authorization: Bearer <access_token>`。
> - 所有 JSON 接口统一返回 `Result<T>`；SSE 接口除外。
> - 时间字段统一为 ISO 8601 UTC 字符串，如 `2026-11-22T08:00:00Z`。
> - `user_id` 一律从 JWT 解析，不接受前端传入。

## 公共对象

### Result<T>

|字段|类型|说明|
|-|-|-|
|code|int|0 成功，非 0 失败，见错误码|
|message|string|提示信息|
|data|T 或 null|业务数据，即下文各接口的 VO|

### 错误码

|code|含义|
|-|-|
|0|成功|
|1001|参数错误|
|1002|未登录或 Token 失效|
|1003|无权限|
|2001|资源不存在|
|2002|资源冲突（唯一键、外键占用等）|
|3001|模型调用失败|
|3002|技能执行失败|
|4001|路径越界|

> 业务错误统一 HTTP 200 + `code` 非 0；鉴权失败返回 401，参数校验失败返回 422。

|字段|类型|说明|
|-|-|-|

|page|int|当前页，从 1 开始|
|page_size|int|每页条数|
|items|array|当前页数据|

## 用户接口

### 创建用户
**接口：**`api/v1/user/create`
**方式：**`POST`
**鉴权：**无（开放注册可通过配置关闭）

**请求 DTO：**`UserCreateDTO`

|字段|类型|必填|说明|
|-|-|-|-|
|username|string|是|3-64 位，字母、数字、下划线，全局唯一|
|password|string|是|6-128 位，服务端 bcrypt 哈希后存储|
|nickname|string|否|显示昵称，为空时使用 username|

**响应 VO：**`UserVO`

**说明：**username 重复返回 `2002`。

### 删除用户
**接口：**`api/v1/user/delete/{id}`
**方式：**`DELETE`
**鉴权：**需登录，仅本人

**路径参数：**`id` 用户 UUID

**请求 DTO：**无

**响应 VO：**`null`

**说明：**级联删除该用户的模型配置、会话和消息，不可恢复。

### 修改用户信息
**接口：**`api/v1/user/modify/{id}`
**方式：**`PUT`
**鉴权：**需登录，仅本人

**路径参数：**`id` 用户 UUID

**请求 DTO：**`UserModifyDTO`

|字段|类型|必填|说明|
|-|-|-|-|
|nickname|string|否|新昵称|
|old_password|string|否|修改密码时必填|
|new_password|string|否|新密码，6-128 位|

**响应 VO：**`UserVO`

**说明：**只传需要修改的字段；改密码时 old_password 和 new_password 必须同时提供。

### 查询用户列表
**接口：**`api/v1/user/list`
**方式：**`GET`
**鉴权：**需登录（建议仅部署管理员）

**Query 参数：**

|字段|类型|必填|说明|
|-|-|-|-|
|page|int|否|默认 1|
|page_size|int|否|默认 20，最大 100|
|keyword|string|否|按 username / nickname 模糊搜索|

**请求 DTO：**无

**响应 VO：**`PageVO<UserVO>`

### 登录
**接口：**`api/v1/user/login`
**方式：**`POST`
**鉴权：**无

**请求 DTO：**`UserLoginDTO`

|字段|类型|必填|说明|
|-|-|-|-|
|username|string|是|登录账号|
|password|string|是|明文密码，服务端比对哈希|

**响应 VO：**`TokenVO`

**说明：**账号或密码错误统一返回 `1001`，不区分具体原因。

### 获取当前用户
**接口：**`api/v1/user/me`
**方式：**`GET`
**鉴权：**需登录

**请求 DTO：**无

**响应 VO：**`UserVO`

## 模型配置接口

> 平台不提供模型选项，用户自行维护连接配置，类似 CCswitch：一套配置包含名称、接口地址、模型名和 API KEY。`user_id` 从 JWT 取，只能操作自己的配置。

### 新增模型配置
**接口：**`api/v1/model/new`
**方式：**`POST`
**鉴权：**需登录

**请求 DTO：**`ModelCreateDTO`

|字段|类型|必填|说明|
|-|-|-|-|
|display_name|string|是|配置名称，如 “DeepSeek 官方”|
|provider|string|否|提供方标识，默认 `custom`，仅用于界面预填|
|model_name|string|是|请求接口时的模型名，如 deepseek-chat|
|base_url|string|是|接口地址，如 https://api.deepseek.com/v1|
|api_key|string|是|用户自己的 API KEY|
|context_window|int|否|默认 128000|
|max_output_tokens|int|否|默认 4096|
|is_default|boolean|否|默认 false；设为 true 时取消同用户其他默认|
|is_active|boolean|否|默认 true|

**响应 VO：**`ModelVO`

**说明：**API KEY 使用 AES-256-GCM 加密后写入 `model_config`，响应只返回掩码。

### 删除模型配置
**接口：**`api/v1/model/delete`
**方式：**`DELETE`
**鉴权：**需登录

**Query 参数：**

|字段|类型|必填|说明|
|-|-|-|-|
|id|string|是|模型配置 UUID|

**请求 DTO：**无

**响应 VO：**`null`

**说明：**软删除（写 `deleted_at`）。已引用该配置的会话和消息将其置空，回退到用户默认模型。

### 修改模型配置
**接口：**`api/v1/model/modify`
**方式：**`PUT`
**鉴权：**需登录

**请求 DTO：**`ModelModifyDTO`

|字段|类型|必填|说明|
|-|-|-|-|
|id|string|是|模型配置 UUID|
|display_name|string|否|新配置名称|
|provider|string|否|提供方标识|
|model_name|string|否|接口模型名|
|base_url|string|否|接口地址|
|api_key|string|否|不传表示保持原 KEY；传新值则覆盖|
|context_window|int|否|上下文窗口|
|max_output_tokens|int|否|单次最大输出|
|is_default|boolean|否|设为 true 时取消同用户其他默认|
|is_active|boolean|否|是否启用|

**响应 VO：**`ModelVO`

### 查询模型配置列表
**接口：**`api/v1/model/list`
**方式：**`GET`
**鉴权：**需登录

**Query 参数：**

|字段|类型|必填|说明|
|-|-|-|-|
|only_active|boolean|否|默认 true|

**请求 DTO：**无

**方式：**`POST`

**请求 DTO：**`ModelTestDTO`

## 对话接口

### 发送对话信息
**接口：**`api/v1/chat/send`
**方式：**`POST`
**鉴权：**需登录
**响应类型：**`text/event-stream`（SSE，不使用 `Result` 包装）

**请求 DTO：**`ChatSendDTO`

|字段|类型|必填|说明|
|-|-|-|-|
|session_id|string|是|会话 UUID|
|message_id|string|是|客户端生成的用户消息 UUID，用于幂等|
|content|string|是|用户输入内容|
|attachments|string[]|否|引用工作区文件 ID 列表|
|model_config_id|string|否|临时覆盖会话模型配置，不传则用会话配置|

**SSE 事件：**

|event|data 字段|说明|
|-|-|-|
|message_start|message_id、session_id、role|开始生成 assistant 消息|
|delta|message_id、content|文本增量|
|tool_call|run_id、message_id、skill、args|开始调用技能|
|tool_result|run_id、status、summary、files|技能执行完成|
|message_end|message_id、input_token、output_token、finish_reason|单条消息结束|
|done|session_id、message_id、usage|本轮对话结束|
|error|code、message、message_id|出错|

**说明：**

- `message_id` 重复提交时直接返回已存在的消息，不重复生成；
- 客户端断开连接时，服务端终止模型请求和技能子进程，消息状态标记为失败；
- 技能调用的详细产物记录在 `skill_run`，`tool_result.files` 只返回工作区相对路径。

|字段|类型|必填|说明|
|-|-|-|-|
|since|string|否|上次同步返回的 `next_since`，首次不传|
|limit|int|否|默认 200，最大 500|

**请求 DTO：**无

**响应 VO：**`SyncPullVO`

|字段|类型|说明|
|-|-|-|
|sessions|SessionVO[]|新增或更新的会话|
|messages|MessageVO[]|新增或更新的消息|
|deleted_session_ids|string[]|已删除会话 ID|
|deleted_message_ids|string[]|已删除消息 ID|
|next_since|string|下次拉取时传回|

### 推送本地变更
**接口：**`api/v1/sync/push`
**方式：**`POST`
**鉴权：** 需登录

**请求 DTO：** `SyncPushDTO`

|字段|类型|必填|说明|
|-|-|-|-|
|sessions|SessionVO[]|否|客户端离线创建的会话|
|messages|MessageVO[]|否|客户端离线创建的消息|

**响应 VO：**`SyncPushVO`

|字段|类型|说明|
|-|-|-|
|accepted_session_ids|string[]|已接收的会话 UUID|
|accepted_message_ids|string[]|已接收的消息 UUID|
|conflicts|string[]|冲突的资源 UUID|

**说明：** 以客户端生成的 UUID 做幂等，同一 ID 重复推送直接视为已接收。
